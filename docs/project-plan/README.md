# StructuraX

StructuraX is a Full-Stack SaaS Construction Planning and House Design Platform.

## Tech Stack

### Frontend

* Next.js
* React
* Tailwind CSS
* Redux Toolkit
* React Query

### Backend

* Spring Boot
* Spring Security
* JWT Authentication
* Hibernate/JPA

### Database

* MySQL

## Features

* Plot Configuration
* House Design Planner
* Cost Estimation Engine
* Engineer Marketplace
* Admin Dashboard
* Project Collaboration
